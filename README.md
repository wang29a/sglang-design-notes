# SGLang 每日设计学习

每天北京时间 15:00，从真实 SGLang 源码中学习三个相互关联的设计。围绕一个请求连续解释问题、直观方案的限制、关键洞察、状态变化、不变量、取舍与验证方法，逐步从请求生命周期深入调度、缓存、执行后端与分布式架构。

源码 checkout 通过 `SGLANG_SOURCE_DIR` 指定；默认使用学习仓库同级的 `sglang` 目录。每篇记录完整源码提交及固定版本链接，不修改上游源码，也不把静态阅读描述成 GPU 运行或性能实测。已学问题与交付状态记录在 [index.json](index.json)，后续按 [学习路线](ROADMAP.md) 延伸；同一天重试补齐原来的三篇，不重复新增。
